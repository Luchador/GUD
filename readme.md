# Goldeneye UpDate (GUD)

GUD is a fork of the GoldenEye decompilation repo. Some of the goals of this project are:
* Code cleanup and documentation.
* Removing dead code and putting all debug code behind preprocessor directives.
* Game optimization on the N64.
* A laundry list of new features and bug fixes. I'm still deciding what to do.

**Note: This repository does not include all assets necessary for compiling the ROMs. A prior copy of the game is required to extract the assets.**
